# Jan Bodriyar — Virtual Reallik va Axloqiy Muammolar

Bu repozitoriyada Jan Bodriyar (Jean Baudrillard) g'oyalari asosida virtual reallik va axloqiy muammolar tahlilini ifodalovchi prezentatsiya joylashgan.

## 📂 Fayllar

- **`Bodriyar_Virtual_Reallik.pptx`** — Tayyor PowerPoint prezentatsiyasi (10 ta slayd, 16:9 format)
- **`create_presentation.py`** — Prezentatsiyani qayta yaratuvchi Python skripti

## 📑 Prezentatsiya tarkibi

1. Sarlavha
2. Reja
3. Jan Bodriyar haqida (1929–2007)
4. Simulyakr va Simulyatsiya
5. Giperreallik nazariyasi
6. Tasvirning to'rt bosqichi
7. Virtual reallikning falsafiy tabiati
8. Axloqiy muammolar (6 ta asosiy masala)
9. Zamonaviy raqamli olamga ta'siri
10. Xulosa

## 🛠️ Skriptni qayta ishga tushirish

```bash
pip install python-pptx
python3 create_presentation.py
```

Natijada `Bodriyar_Virtual_Reallik.pptx` fayli yangilanadi.

- Baudrillard, J. (1970). *La Société de consommation*
